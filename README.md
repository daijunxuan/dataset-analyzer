# Dataset Analyzer

[![Tests](https://github.com/daijunxuan/dataset-analyzer/actions/workflows/test.yml/badge.svg)](https://github.com/daijunxuan/dataset-analyzer/actions/workflows/test.yml)

A Python command-line tool for automated dataset analysis.

This project analyzes CSV datasets, generates statistical summaries, detects missing values, and exports reports in JSON format.

---

## Features

- Load CSV datasets
- Analyze dataset structure
- Count missing values
- Generate numerical summaries
- Export JSON reports
- Logging system
- Configuration management
- Unit testing with pytest
